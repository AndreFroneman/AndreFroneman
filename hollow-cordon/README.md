# HOLLOW CORDON

A 2D side-view zombie survival shooter. Marrow Falls has been sealed behind the military's *Cordon Directive 9* after the outbreak of the Pale Fever — you are inside.

## Launch

The game is plain HTML5/JavaScript with no dependencies and no build step. Serve the folder with any static web server and open it in a desktop browser (Chrome, Edge or Firefox):

```bash
cd hollow-cordon
python3 -m http.server 8000
```

Then open <http://localhost:8000> and click once to start (the click unlocks audio).
